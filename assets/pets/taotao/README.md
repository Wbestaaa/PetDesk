# 桃桃动作资源

桃桃是 PetDesk 内置的九姿态图片桌宠。动作资源由项目自己的橘猫形象作为身份参考生成，没有复制第三方桌宠角色或帧图。

## 动作

`idle`、`walk`、`stretch`、`play`、`feed`、`study`、`sleep`、`celebrate`、`alert`

每个动作使用独立透明 WebP，并通过 `src/pet.js` 的状态触发和 `src/pet.css` 的短循环动效组合展示。映射关系保存在 `manifest.json`。

## 生成规格

- 同一只橘色虎斑幼猫、绿色大眼、深绿色项圈和金色扣。
- 3×3 等分动作图：待机、行走、伸展、羽毛玩耍、吃饼干、读书、睡觉、庆祝、提醒。
- 源图使用纯洋红背景，本地去背后裁切，并压缩为九张 418×418 透明 WebP。
- 不包含第三方角色、商标或水印。
