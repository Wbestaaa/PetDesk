# PetDesk

PetDesk 是一款面向 Windows 11 的自定义桌宠与轻量效率工具。桌宠运行在透明、无边框、可置顶的窗口中；控制中心提供桌宠工坊、番茄专注、Todo、提醒、习惯打卡和外观设置。

## 当前功能

- 透明桌宠窗口：拖动、置顶、托盘、隐藏、鼠标穿透、开机启动。
- 标准动作模式：九类动作、16 方向和统一触发规则；角色包规范见 [`docs/PET_ACTION_PATTERN.md`](docs/PET_ACTION_PATTERN.md)。
- 内置角色：桃桃与照片卡通化人物“毕业花花”，均提供九种独立动作；花花保留长黑发、人物五官、花饰学士帽、粉色领口、黑色学位服与多彩花束，并拥有专属毕业主题回复。
- 桃桃动作资源：九张独立透明 WebP 动作图，右键互动会同时切换姿态、播放明显动效、显示动作标签并给出台词。
- 桌面互动：按住身体拖动、拖动行走、快速放手庆祝、悬停玩耍、空闲自主移动、单击抚摸、双击打开控制中心和分组右键动作菜单。
- 正反馈成长：抚摸、玩耍、伸展和合理拖动提供即时默契反馈；完成待办、习惯和专注获得更多默契并可升级，重复互动带有冷却。
- 桌宠工坊：上传 PNG/JPG/WEBP；离线生成像素单图预览，或通过 AI 一次生成角色一致的九动作套装。动作表会自动切分、去除背景、保存并接入现有动作系统。
- 自定义桌宠管理：单图与九动作桌宠均可选择和删除；删除的本地素材进入 Windows 回收站。
- 可视化 AI 配置：直接在“设置 → AI 图片服务”填写 API URL、API Key 和图片模型，支持连接测试；API Key 使用 Windows DPAPI 安全存储，不再要求环境变量。
- 专注计时：15/25/50 分钟快捷选项和 1–240 分钟自定义时长，支持暂停、重置、完成统计、桌宠陪读与系统通知。
- Todo：优先级、完成、删除和统计。
- 提醒与闹钟：一次性提醒、每天重复、桌宠气泡和 Windows 通知。
- 习惯：每日打卡与累计次数。
- 天气：按城市查询当前天气和未来四天预报；使用 Open-Meteo，无需读取系统定位。
- 本地持久化：数据保存在 Electron 的 `userData` 目录，不上传到服务器。

## 在 Windows 11 上运行

普通用户建议从 [GitHub Releases](https://github.com/Wbestaaa/PetDesk/releases) 下载安装版或免安装版，直接运行，不需要安装 Node.js。

如果下载的是源码：

1. 安装 [Node.js LTS](https://nodejs.org/)。
2. 解压工程，双击 `Start-PetDesk.cmd`（推荐）或 `开始使用.bat`。它会在首次启动时安装运行组件，然后打开 PetDesk。

也可以在文件夹内打开终端。若 VS Code 使用 PowerShell，Windows 执行策略可能会拦截 `npm.ps1`，此时直接调用不会经过 PowerShell 脚本的 `npm.cmd`：

   ```powershell
   npm.cmd install
   npm.cmd start
   ```

或者在 VS Code 按 `Ctrl+Shift+P`，运行 “Terminal: Select Default Profile”，选择 “Command Prompt”。如果你确实希望继续使用 PowerShell，也可在确认组织策略允许后执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，再重新打开终端。

## 打包为安装程序

```powershell
npm run pack:win
```

也可以直接双击 `Build-Windows.cmd`（推荐）或 `构建Windows安装包.bat`。完成后到 `dist` 文件夹中找到：

- `PetDesk-0.2.0-setup-x64.exe`：安装版。
- `PetDesk-0.2.0-portable-x64.exe`：免安装版。

## 连接 AI 图片服务

像素单图预览不需要联网。Q 版、写实、水彩以及完整九动作生成会调用兼容 OpenAI Images Edit 的 API，API 使用量不包含在 ChatGPT 订阅中。

1. 打开控制中心的“设置”。
2. 在“AI 图片服务”中填写 API URL、图片模型和 API Key。OpenAI 默认 URL 是 `https://api.openai.com/v1`，默认图片模型为 `gpt-image-2`。
3. 点击“保存并测试”。成功后回到“桌宠工坊”，上传原图并点击“一键生成完整九动作”。

API Key 不会写入项目源码或普通状态文件，而是通过 Electron `safeStorage` 交给 Windows DPAPI 加密后保存在当前用户的应用数据目录。界面只显示是否已配置，不会回显密钥。为了兼容旧版本，未配置应用内密钥时仍可读取 `OPENAI_API_KEY` 环境变量。

第三方兼容 URL 会收到你的 API Key、原图和提示词；请只使用你信任的 HTTPS 服务地址。

## 使用方式

- 双击桌宠：打开控制中心。
- 按住桌宠：拖动到屏幕内任意位置；拖动时自动显示行走动作。
- 右键桌宠：从“陪伴、效率、更多”分组中选择抚摸、玩耍、伸展、随机互动、读书、庆祝、睡觉、提醒预览或主动说话。
- 拖动桌宠：移动时切换行走动作并朝向拖动方向；松手后停在屏幕工作区内并保存位置，快速移动会触发庆祝反馈。
- 控制中心右上角：清楚显示桌宠当前状态，可隐藏并再次恢复。
- 桌宠工坊：选择原图主体类型，生成单图预览或完整九动作；生成过程中会显示“准备、生成、切分透明化、保存、完成”的可视进度。
- 我的桌宠：点击卡片切换；自定义卡片左上角的删除按钮会先确认，再将素材移入回收站。内置角色不会被删除。
- 托盘图标：桌宠隐藏时左键直接恢复；显示时左键打开控制中心；右键还有显示/隐藏、快速专注和退出。
- 如果开启“鼠标穿透”后无法点击桌宠，请通过系统托盘打开控制中心并关闭该选项。

## 开发说明

项目没有前端框架和远程运行时依赖，界面由原生 HTML/CSS/JavaScript 实现。Electron 主进程负责窗口、托盘、系统通知、定时器、文件选择和本地数据；渲染进程仅通过受限的 preload API 访问这些能力。

```text
PetDesk/
├─ main.js              Electron 主进程
├─ preload.js           安全 IPC 桥
├─ src/
│  ├─ panel.*           控制中心
│  ├─ pet.*             透明桌宠和动作绘制
│  ├─ pet-catalog.js     内置角色目录与素材类型
│  ├─ pet-actions.js     九类动作、16 方向与触发模式
│  ├─ ai-config.js       AI 地址校验、九动作提示词、切分与透明化
│  ├─ weather.js         天气数据转换
│  └─ state.js           默认数据与闹钟计算
├─ docs/                 角色包与动作规范
├─ assets/pets/          桃桃与毕业花花的九姿态动作包
└─ tests/                状态、动作、天气、AI 配置与透明化测试
```

## 隐私提示

本地功能不需要登录。只有主动点击 AI 单图或九动作生成时，选中的图片及提示词才会发送给你配置的 AI API。请不要上传无权处理或包含敏感信息的图片。

天气功能只在用户主动输入城市或刷新已保存城市时联网，不读取 Windows 定位。默认使用 Open-Meteo 公共接口；商用发布前请确认其最新许可与服务条款。地点搜索数据来源于 GeoNames。
